# Predicting Aircraft Damage from Wildlife Strikes

Machine learning project predicting whether a wildlife strike results in aircraft damage using flight characteristics, wildlife attributes, and environmental conditions.

## Dataset

FAA Wildlife Strike Database (`data/Public.xlsx`), containing reported wildlife strike incidents, aircraft and flight characteristics, wildlife information, environmental conditions, and resulting damage.

## Goal

Use supervised machine learning classification to predict aircraft damage and identify factors associated with damage risk. The project will compare Logistic Regression, Decision Tree, Random Forest, and Gradient Boosting/XGBoost models, then evaluate model performance and interpret the factors that most influence damage predictions.
